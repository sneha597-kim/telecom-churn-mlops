## 📊 Power BI Dashboard

An interactive two-page Power BI dashboard was created to transform the exploratory and diagnostic analysis into business-oriented insights.

### Dashboard Pages

#### Page 1 — Executive Churn Overview

Provides a high-level view of the churn problem using KPIs and key churn patterns.

Includes:

- Total Customers
- Churned Customers
- Overall Churn Rate
- Average Monthly Charges
- Churn by Contract
- Churn by Internet Service
- Churn Rate by Contract
- Churn Rate by Internet Service
- Churn Rate by Customer Tenure
- Churn Rate by Monthly Charges

#### Page 2 — Customer Churn Analysis

Provides a deeper analysis of customer characteristics and the factors associated with churn.

The page allows deeper investigation of customer segments and helps identify patterns that can later be used during machine learning feature analysis.

### Interactive Features

The dashboard includes interactive filters that allow users to explore different customer segments based on:

- Churn
- Contract type
- Internet service
